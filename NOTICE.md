## Nielsen-Kellerman protocol documentation

This integration was written with reference to Nielsen-Kellerman Co. (NK)
developer documentation (the LiNK Communications Protocol, Kestrel Weather
Protocol and related documents), obtained through NK's developer documentation
request process. Those documents are proprietary and confidential to NK and are
**not** included in, reproduced in, or distributed with this repository. The
code contains only the numeric identifiers (UUIDs, command, field and unit
codes) and the behaviour required to interoperate with NK devices, together
with observations made on physical devices.

If you intend to build on the protocol layer beyond what is implemented here,
request the documentation from NK directly rather than relying on this code as
a specification.
